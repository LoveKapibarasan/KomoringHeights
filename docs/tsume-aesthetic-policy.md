# 詰将棋生成の審美方針

## 目的

この生成器は「合法かつ一意に詰む局面」と「発表に値する詰将棋作品」を区別する。
完全作であることは作品評価の加点要素ではなく、審美評価へ進むための最低条件とする。
手数だけが長い追い詰めを、正式な生成結果として保存してはならない。

## 二段階ゲート

### 1. 完全性ゲート (`perfect`)

完全探索済み、一意解、早詰・余詰・不詰・禁手・駒余り・不要駒なしを要求する。
この判定は従来どおり詰将棋の正しさだけを表し、美しさを意味しない。

### 2. 審美ゲート (`aestheticPass`)

完全性ゲート通過後、次をすべて要求する。

- 7手以上
- 機械的な追い詰めでない
- 捨駒、連続捨駒、大駒捨て、開き王手、両王手、玉方の駒による応手など、解析可能な構成要素が一つ以上ある
- `aestheticScore >= 35`

不合格候補も検証結果では `perfect:true` になり得るが、正式生成物には保存しない。
JSONの `aestheticPass` と `aestheticReasons` に採否と理由を記録する。候補がなければゼロ件を返し、品質条件を緩めて穴埋めしない。

## 追い詰めの検出

作意中の次の比率を測る。

- 攻方着手のうち、着手駒が玉に隣接して王手した割合
- 玉方応手のうち、玉移動だった割合

両者の平均を `chaseRatio` とする。攻方が3手以上指し、構想的な捨駒・開き王手・両王手・玉以外の応手がなく、`chaseRatio >= 0.75` または玉移動応手率が90%以上なら `chasing mate` と判定する。この候補は審美ゲートで拒否し、`aestheticScore` を最大20、`totalScore` を最大25に制限する。

これは追い詰め検出の最初の保守的な規則である。誤検出を避けるため、捨駒や合駒・移動合を含む作品は比率だけで排除しない。

## スコアの原則

- `legalityScore` と `uniquenessScore` は検証結果であり、審美性の代用品にしない。
- `lengthScore` は単独で採用条件にならない。
- 単なる駒打ちや成りは、それだけでは技巧として加点しない。
- `techniqueScore` は捨駒、大駒捨て、連続捨駒、開き王手、両王手、玉以外の応手を中心に算出する。
- `complexityScore` は根元の合法王手数ではなく、同手数変化、玉以外の応手、開き王手を中心に算出する。
- 追い詰めには明示的な上限制裁を適用する。
- `originalityScore=50` は外部作品データベースと比較していない状態の中立値であり、独創性の証明ではない。

## 生成戦略の段階的改善

現在の局面乱数生成と完全探索に加えて、次の順に実装を発展させる。

1. 美しい収束の抽象テンプレートを作る（限定合、邪魔駒消去、不成、開き王手、連続捨駒など）。
2. 収束局面から逆算して序奏を加え、構想を壊す派生を捨てる。
3. 各着手が退路・利き・持駒・後続手へ与える効果を解析し、「手の意味」を記録する。
4. 複数の評価軸の Pareto frontier を保持し、総合点だけで候補を淘汰しない。
5. 受賞作・入選作・凡作・不完全作を用いた比較ランキングモデルを導入する。
6. canonical ID、手順構造、収束グラフを既存作品群と比較し、類似作を除外する。

学習モデルを導入する場合も、完全性判定をモデルへ委ねてはならない。合法性と完全性はAND/OR完全探索、審美順位だけを人間評価由来のモデルが担当する。

## 現時点の限界

現在実装されているのは、二段階ゲート、追い詰め検出、基本的な技巧解析、生成時の拒否理由出力までである。限定打、中合、打診、伏線と回収、収束の統一感はまだ厳密に意味解析できない。未検出の項目を推測で加点せず、今後、全変化比較に基づいて追加する。
