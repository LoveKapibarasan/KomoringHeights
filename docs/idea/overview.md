# 概要

## このプロジェクトは何か

KomoringHeights は **df-pn+ アルゴリズムを核とする詰将棋専用エンジン**で、[やねうら王 (YaneuraOu)](https://github.com/yaneurao/YaneuraOu) のフレームワーク上に構築されています。本フォークはそこに **詰将棋の自動生成・完全性検証・美的評価** の実験系を追加したものです。

## 何を目指しているか

「解ける」だけでは詰将棋にならず、以下の条件を満たして初めて **完全な作品** となります。

1. **作意成立**: 攻方が正しく指せば必ず詰む
2. **余詰なし**: 攻方の初手（および途中手順）に別解がない
3. **無駄合なし**: 意味のない中合を無効化
4. **駒余りなし**: 詰め上がりで攻方に残り駒がない（39枚制）
5. **芸術性**: 捨駒・打歩詰誘致・両王手など、指し手に技巧がある

このプロジェクトは、上記条件を **機械が判定できる形に定式化** し、そこから自動生成にまで踏み込むことを目的にしています。

## KomoringHeights 本体との関係

- **KomoringHeights 本体**: df-pn+ による詰み探索エンジン。詰みの有無・最短手数を高速に判定する
- **本フォークの追加部分** (`source/engine/user-engine/tsume_*.hpp`, `user-search.cpp`): 生成・完全性検証・美的評価・JSON 出力
- 全ての追加コードは `user tsume_*` という USI 拡張コマンドを通じて呼び出されます

## 想定ユーザー

- 詰将棋作家向けの **創作補助**（近傍探索・変形候補生成）
- 詰将棋研究者向けの **データセット生成**（機械学習用の大規模問題集）
- **完全性検証ツール**（既存作品の余詰・駒余りチェック）

## 開発の現在地

直近のコミット履歴を見ると、以下のエリアが active です。

- **9手詰めのシード幾何**: 密配置テンプレート（歩壁 + 後衛）
- **逆算法の拡張**: 中間ステップの BFS 化、39枚直接パス
- **美的フィルタ**: 追い詰め判定、余剰駒検出、変同カウント
- **X 変数出力**: 廣瀬 1998 の回帰変数 X3〜X12 を JSON に付与
- **データセット化**: KIF → SFEN 一括変換ツール
